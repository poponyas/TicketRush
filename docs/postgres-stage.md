# PostgreSQL: актуальный этап

Модель проекта обновлена до Event → Session → TicketType.

Смотри [новую модель, запуск и контракт CreateEvent](domain-and-create-event.md).

Объяснение каждой сущности и файла — в [разборе проекта](project-walkthrough.md).

Команды:

```sh
make seed
make migrate-version
make run
```

Seed предназначен для локальной разработки. Авторизация JWT ещё не реализована;
для Postman используется явно включаемая dev identity на loopback-адресе.
`make seed` проверяет начальную схему, применяет миграции и добавляет dev-данные.
`make run` выполняет эти шаги перед запуском сервера и останавливается при ошибке.

Точная старая схема 001 или 002, созданная вручную, распознаётся через
`scripts/migration_prepare.sql`: он согласует журнал migrate после проверки
колонок, ограничений и индексов, сохраняя данные. Неизвестная схема или dirty
на более поздней версии требуют отдельного разбора; автоматически они не сбрасываются.
